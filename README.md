# 恋愛哲学ジェネレーター（renai-tetsugaku）

既読無視や失恋といった身近な恋の痛みを、哲学の言葉で「まじめすぎる恋愛論」に変換して無限生成する、単一ファイルの静的Webサイト。

**公開URL**: https://otani-png.github.io/renai-tetsugaku/

---

## 構成

- `index.html` … HTML / CSS / JS をすべて含む単一ファイル。ビルド不要。
- ホスティング … GitHub Pages（リポジトリ: `otani-png/renai-tetsugaku`）

## 仕組み

「**恋愛語 × 哲学概念 × 哲学的結論**」をランダムに組み合わせ、テンプレート文に流し込んで一節を生成する。

- 各単語には**用語解説**を表示（真剣な言葉遊びとして成立させるための種明かし）。
- 生成回数は **localStorage**（自分の回数）と **counterapi.dev**（人類全体の回数）で集計。
- 演出：初回は「深淵を覗く」の文字が**砂のように散る**。2回目以降は**靄でクロスフェード**。
- `prefers-reduced-motion` を有効にしているユーザーにはアニメを抑制。
- 生成後に **「𝕏 この一節をシェア」** ボタンが出て、生成文＋出典＋URLでポストできる。

## ローカルで開く

静的ファイルなので基本はブラウザで `index.html` を開くだけ。
グローバルカウンタ（外部API）も含めて確実に動かすなら、簡易サーバー経由が安全：

```
python -m http.server 8765
# → http://localhost:8765/index.html
```

## 単語・テンプレートを増やす

`index.html` 内の `<script>` にある配列を編集する：

| 配列 | 役割 | 色 | 解説の追加先 |
|------|------|----|--------------|
| `love` | 恋愛語 | ピンク | `loveDesc` |
| `phil` | 哲学概念 | 青 | `philDesc` |
| `ending` | 哲学的結論 | 緑 | `endDesc` |
| `templates` | 文の組み立てパターン | — | — |
| `authors` | 出典（架空） | — | — |

新しい単語を足したら、対応する `〜Desc` にも解説を1行追加すると用語解説に反映される。

## 広告（Google AdSense）

- ページ下部に広告枠プレースホルダ（`#ad-slot`）を用意済み。審査通過後にこの `div` を差し替える。
- ⚠️ **GitHub Pages の `*.github.io` サブドメインは AdSense 審査で弾かれる**（「有効なトップレベルドメインでない」と判定される）。
  → 独自ドメインを取得して GitHub Pages に設定してから申請する必要がある。
